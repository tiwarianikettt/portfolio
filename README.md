# Aniket Tiwari | Personal Portfolio

A responsive personal portfolio website that showcases my background, skills, projects, achievements and learning journey as a B.Tech Computer Science student.

**🌐 Live site:** [tiwarianikettt.github.io/portfolio](https://tiwarianikettt.github.io/portfolio/)

##  Features

- **Responsive design** that adapts to phones, tablets and desktops using media queries
- **Multi-page layout:** Home, About, Projects and Contact
- **Project showcase** with tech stack, key features, and Live Demo, GitHub and Video Demo buttons for each project
- **About section** covering education, skills, achievements and extracurricular activities
- **Smooth CSS transitions and animations** for a polished feel
- **Downloadable resume** (PDF)

## ▶ Run Locally

```bash
# Clone the repository
git clone https://github.com/tiwarianikettt/portfolio.git

# Move into the folder
cd portfolio

# Open index.html in your browser
```

No build step or dependencies needed. It's plain HTML, CSS and JavaScript.
