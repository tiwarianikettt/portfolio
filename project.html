WEATHER WHIPLASH

An AI-powered web application developed as a hackathon project to analyze racing track conditions through images and videos. The application uses AI-based classification to identify track conditions and provides useful insights and recommendations based on the detected conditions.


Tech Stack

HTML • CSS • JavaScript • Python • FastAPI • OpenCV • CLIP


Key Features
  • Analyze racing track images and videos.
  • Classify track conditions as Dry, Damp, Wet, or Drying.
  • AI-based track condition classification using CLIP.
  • Confidence scores for predictions.
  • Track condition trend analysis.
  • Recommendations based on detected conditions.
